# apriltag_v6 — 칼만 필터 오프라인 검토

v5 실주행 기록(`apriltag_v5/work_dirs/kw/20261001/run/`)에 작은 칼만 필터(EKF)를 **다시 돌려 보는** 도구다.
v5 파일은 읽기만 한다. 차를 움직이는 코드는 없다. 참값(줄자로 잰 실제 위치)이 없어서 **정확도가 아니라 일관성**만 본다.

```bash
cd apriltag_v6
python src/ekf.py                         # 식끼리 맞는지 자체 시험 (논리 확인 — 정확도 아님)
python tools/ekf_replay.py                # 10/1 kw run 전부 → work_dirs/ekf_replay/<시각>/ (decisions.csv · summary.json)
python tools/ekf_replay.py --psi first    # PnP 방향은 첫 판단에서만, 그 뒤는 자이로로만
python tools/ekf_replay.py --center learned   # 회전중심을 학습 파일 값으로 (이 run 들로 맞춘 값이라 순환)
```

## 필터
- 상태: 카메라 좌우 L · 앞거리 F · 카메라 방향 ψ (태그 기준, v5 부호 — 기록 11,916장으로 확인)
- 움직임(서 있는 판단 사이): 회전 = 자이로 각을 회전중심 둘레로 · 직진 = 학습 파일 정속 × (명령 쥔 시간 − 출발지연)
- 측정(판단마다 하나): 화면위치 β · 3D 거리 d · PnP 방향
- 태그 한 장으로는 "태그 둘레로 통째로 돈 자세" 를 β·d 가 못 가른다 — 기준 방향은 PnP 방향으로만 잡힌다.

## 숫자 출처 (새로 찍은 값 없음)
| 값 | 출처 |
|---|---|
| β 측정 흔들림 | 그 run 의 출발 60초 정지 — 0.5초 묶음 평균의 sd |
| 거리 측정 흔들림 | 그 run 의 `baseline.json` `sigma_drift_distance_m`, 거리²에 비례 (v5 σ 모델) |
| PnP 방향 흔들림 | **다른** run 들의 판단마다 (PnP 방향 − 자이로) sd |
| 자이로 눈금 오차 | 학습 파일 맞춤 0.9909 ±0.0047 → √(0.0091² + 0.0047²) |
| 자이로 흐름 | 60초에 0.6° (2026-10-01 VM) |
| 회전중심 | 그 run 의 config (calibrate 스윙 — 이 run 들과 다른 자료), 흩어짐 `ROT_CENTER_RMS_MM` |
| 직진 앞뒤 흔들림 | **다른** run 카메라 직진들의 (실제 − 시간 식) RMS |
| 판단 시각 자이로 창 0.5 s | v5 추정 창과 같은 길이 |

## 2026-10-16 첫 결과 (10/1 kw 5판, 기본 설정)
- NIS(1 이면 흔들림 값이 정직): β 0.8~5.1 · 거리 2.2~18.9 · PnP 방향 0.6~1.1.
  → 정지 60초로 잰 β·거리 흔들림은 **자세가 바뀌면 너무 작다.** 5° 이하 제자리 회전 뒤에도 예측과 β 0.02~0.17°, 거리 1~11 mm 가
  어긋났다(정지 흔들림 β 0.001° 급 — 화면 위치·자세에 따른 치우침, 공장 왜곡 계수 0 의 영향일 수 있음). 16~17° 회전 뒤는 β 0.4~0.6° ·
  거리 56~67 mm (회전중심 값 오차도 섞임). 사이드스텝 시간 직진 뒤 거리 혁신 15~45 cm.
- PnP 방향 − 자이로로 이어 온 방향: RMS 1.5~1.9°.
- 제자리 회전 뒤 좌우 변화 − 기하: PnP 5~31 cm · 필터 1~6 cm (필터는 예측에 같은 기하를 써서 작게 나오는 부분이 있다).
- 필터 좌우 − PnP 좌우 (태그 3~5 m): RMS 5~15 cm. 어느 쪽이 맞는지는 참값이 없어 모른다.
- 마지막 판단에서 필터가 말하는 흔들림: 좌우 ±2~5 cm · 방향 ±0.4~0.6° — PnP 방향 오차를 판단마다 독립으로 봐서 **과신일 수 있다.**
- `--psi first` 에서 방향 측정 없이도 방향 흔들림이 0.16° 까지 줄어든 run 이 있다 — 볼 수 없는 방향을 선형화가 본다고 착각하는
  EKF 의 알려진 과신. 필터의 σ 를 그대로 믿으면 안 된다는 증거.

## 다음에 필요한 것

- β·거리의 자세별 치우침을 줄이려면 컬러 카메라 렌즈 보정(바둑판)을 다시 해 볼 것.
