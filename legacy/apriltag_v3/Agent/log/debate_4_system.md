## 남는 리스크 (judge top 2)
- **FM8b + 미검증 차량 워치독**: 같은 프로세스의 TX 스레드·데드맨은 호스트와 함께 얼고, 명령 소실 시 거동은 표준이 보장하지 않으며 제조사·OEM 설정으로 정지/경고만/속도 컷백으로 갈린다(PDO Timeout 0 = 워치독 없음 가능). 리모컨 수신기가 살아 있으면 동일 ID 이중 송신이 잠복하거나 비결정 bus-off. **precheck (1) 전에는 어떤 forward 실주행도 안전 근거가 없다.**
