# Forklift Docking System - Current Problem Definition

## 세부 문제점

### 1. Detection noise
- AprilTag로부터 `forward / lateral / heading` 값을 추출할 때 프레임별 측정값이 흔들림.
- 같은 위치에서도 값이 일정하지 않아 제어 입력이 불안정해질 수 있음.

### 2. 직진 주행 오차
- 직진 명령 후 정지할 때 관성으로 인해 추가 이동이 발생함.
- 명령 전달 및 실행 지연으로 인해 실제 이동량이 예측과 달라질 수 있음.

### 3. 회전 주행 오차
- 목표 각도까지 회전한 뒤 정지 명령을 내려도 관성으로 인해 추가 회전이 발생함.
- 결과적으로 목표 heading과 실제 heading 사이에 오차가 생김.

### 4. 30-frame 기반 측정의 한계
- 현재는 최근 30개 프레임을 모아 측정값을 결정함.
- Detection noise는 완화할 수 있지만, 과거 프레임에 의존하기 때문에 현재 차량 상태를 즉각적으로 반영하지 못함.
- 차량이 이동 중일 경우 측정값에 시간 지연이 발생함.

### 5. Detection 시점과 실제 차량 상태의 시간 불일치
- 이미지 획득 → detection → pose 계산 → 제어 판단 → 명령 전달 → 실제 차량 동작 사이에 지연이 존재함.
- 따라서 제어 시점에서 사용하는 pose는 실제 현재 pose보다 과거 상태일 수 있음.

### 6. Lateral과 heading의 coupling
- Lateral과 heading은 독립적으로 변하지 않음.
- Heading을 보정하면 lateral 위치가 바뀌고, lateral을 보정하는 과정에서 heading이 다시 변할 수 있음.
- 이 때문에 반복적인 재보정이 발생하고 오차가 누적될 수 있음.

### 7. 차량 동역학의 비일관성
- 동일한 차량, 동일한 명령, 유사한 조건에서도 실제 이동량과 정지 거리가 매번 조금씩 달라짐.
- 따라서 `1초 전진 = 0.284m`와 같은 고정식만으로는 높은 정밀도를 보장하기 어려움.

## 상위 문제 분류

| 상위 문제 | 포함되는 세부 문제 |
|---|---|
| **1. Perception 문제** | 1, 4 |
| **2. Timing 문제** | 2 일부, 4 일부, 5 |
| **3. Vehicle dynamics 문제** | 2, 3, 7 |
| **4. Controller 문제** | 6 + 현재 반복 보정 구조 |

> 참고: 4번 문제는 Perception 문제이면서 동시에 Timing 문제이기도 함.  
> 30-frame 방식은 detection noise를 줄이는 대신 latency를 증가시키는 trade-off가 있음.

## 핵심 요약

현재 시스템의 오차는 단일 원인으로 발생하는 것이 아니라 다음 네 계층의 문제가 복합적으로 작용한 결과로 볼 수 있음.

1. **Perception 문제**
   - AprilTag detection 값의 흔들림
   - 과거 frame 기반 측정으로 인한 현재 상태 추정의 한계

2. **Timing 문제**
   - Detection, 계산, 명령 전달, 실제 차량 동작 사이의 지연
   - 측정 시점과 제어 시점 사이의 상태 불일치

3. **Vehicle dynamics 문제**
   - 직진 및 회전 정지 시 관성
   - 동일 조건에서도 반복마다 달라지는 실제 차량 반응

4. **Controller 문제**
   - Lateral과 heading의 coupling
   - 하나를 보정하면 다른 오차가 발생하여 반복적인 재보정이 필요해지는 구조
