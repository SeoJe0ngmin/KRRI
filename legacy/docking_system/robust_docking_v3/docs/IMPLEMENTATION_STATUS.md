## 지금과 장비 연결 후의 경계

현재 구현·가상 검사는 센서 보정 절차, 설정/목표 생성, 조건부 정렬과 일반 접근의 연결, 시간 제한, 비동기 기록의 프로그램 동작을 확인한다. 코드가 측정값을 요구하는 자리에 임의 숫자를 넣어 실차 완료처럼 표시하지 않는다.

카메라·IMU만 연결한 날에는 야외 노출, 태그 검출/흔들림, 실제 카메라 모델, gyro 보정/시각, 영상·깊이 처리량과 화면을 확인할 수 있다. 그날 지게차의 출발 지연·관성·제동 범위를 확인할 수는 없다. 카메라를 손으로 움직인 결과도 지게차 운동 범위를 대신하지 않는다.

차량이 준비되면 차폭/뒤끝·장착 변환·태그 오프셋·콘 통로·진입 깊이, 명령별 출발/제동 범위, 실제 태그 소실 이후의 추적과 최종 정지 오차를 확인해야 한다. 대량 로그로 평균 주행 응답을 학습하는 절차는 요구하지 않는다. 검증 결과가 허용 오차보다 나쁘면 입력 숫자를 낙관적으로 줄여 실행하지 않고 센서 배치/운용 조건/목표 정밀도를 다시 조정해야 한다.

## 2026-10-11 자동 관측 복구 추가

- `PAUSING`/`REOBSERVING`: STOP·관측 정지 확인·안정 구간·재검출 태그 수·히스테리시스 후 현재 위치에서 재계획. 전체 시간/동작 예산을 유지한다.
- SIDESTEP 태그 소실: 연속 절대 위치 추적이 있으면 기존 회전 계약으로 시작 방향에 복귀. 90° 반대 회전은 해당 계약/공간이 있어야 한다. 추적을 완전히 잃으면 자동 회전하지 않는다.
- 정지 중 IMU 영점 재보정: 영상과 중립 명령의 시간 정합, gyro/accel 정지 창, 총 바이어스 변경 상한. yaw와 누적 위치 오차를 초기화하지 않는다. 실측 문턱은 아직 미입력이다.
- CAN 송신 소스와 기존 CAN 설정은 변경하지 않았다. 포크/접기/리치/동시 조향·전진 명령 금지 유지.
- 소프트웨어 회귀 검사는 실제 센서/차량 정밀도 검증을 대신하지 않는다.

## 2026-10-11 최초 태그 탐색 추가

- 최초 센서 준비/정지 확인 후에만 태그 부재를 확인하고 제자리 회전한다. 목표 ID를 발견하면 STOP, 실제 정지 후 여러 새 태그 자세로 위치를 확정한다. 처음부터 보이면 회전하지 않는다.
- 90° 고정이 아니며 한 바퀴 이내 각도 예산과 제동 여유를 사용한다. 초기 자유 원/병진 편차, 연속 상대 추적, IMU, 시작 지연/STOP 응답을 검사한다.
- 초기 완료 후에는 재진입하지 않는다. 일반 주행의 태그 잘림과 사이드스텝 소실은 기존 복구 상태가 담당한다.
- CAN 송신 파일/설정은 그대로다. 탐색 공간·응답·편차 실측값과 검증 근거는 미입력이며 실차 주행은 계속 차단된다.
