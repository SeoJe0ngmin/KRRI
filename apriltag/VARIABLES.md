# 변수 총정리

이 프로젝트에 나오는 숫자를 **어디서 오는가** 로 나눴다. 다루는 법이 다르다.

| 기호 | 뜻 |
|---|---|
| **실측** | 현장에서 자·캘리퍼·스톱워치로 재야 한다. 안 재면 결과가 틀린다 |
| **자동** | 카메라(SDK)가 준다. 우리가 적을 필요 없다 |
| **출력** | 코드가 매 프레임 계산해서 내놓는다. 우리가 정하는 게 아니다 |
| **설계** | 우리가 고른 기준값. 틀리진 않지만 실장비로 조정할 수 있다 |
| **규격** | 이미 근거가 확정됐다. 바꾸면 틀린다 |

---

## 1. 실측 — 현장에서 재야 하는 것

| 이름 | 단위 | 어떻게 재나 | 지금 상태 |
|---|---|---|---|
| `TAG_SIZE_M` | m | 인쇄물의 **검은 테두리 바깥**까지 자로. 거리 오차에 그대로 비례 | 0.200 실측 완료 |
| `TAG_HEIGHT_M` | m | 바닥에서 태그 중심까지 줄자 | 1.60 |
| `CAM_HEIGHT_M` | m | 바닥에서 카메라 렌즈까지 줄자 | 1.20 |
| `CAM_YAW_OFFSET_DEG` | 도 | 태그 정면에 세우고 `heading` 을 읽는다. 그 값이 곧 장착 오차 | **미측정 (0)** |
| `ROT_DEG_PER_SEC` | 도/s | 회전 명령을 N초 주고 `heading` 변화를 나눈다 | **미측정 (15 가정)** |
| `ROT_T0_SEC` | s | 회전 명령 후 실제로 돌기 시작할 때까지 지연 | **미측정 (0.5 가정)** |
| `ROT_MIN_SEC` | s | 이보다 짧으면 아예 안 움직이는 하한 | **미측정 (1.0 가정)** |
| `CORNER_NOISE_PX` | px | 정지 상태로 100프레임 찍어 코너 좌표의 표준편차 | 0.2 가정 |
| `APPROACH_SPEED_MPS` | m/s | 다른 팀이 주행 로그로 적합 | 0.284 실측 완료 |

**미측정 네 개가 지금 가장 큰 위험이다.** 회전 셋은 `sidestep` 시간을 직접 결정한다.

---

## 2. 자동 — 카메라가 주는 것

`config.py` 에 **일부러 안 적었다.** 적으면 해상도를 바꿀 때 어긋난다.

| 이름 | 뜻 | 예시값 (1920×1080) |
|---|---|---|
| `fx`, `fy` | 초점거리 [px]. 거리 계산의 기준 | 1359.2 / 1359.0 |
| `cx`, `cy` | 광축이 화면에서 지나는 점 [px] | 956.9 / 571.3 |
| `distortion` | 렌즈 왜곡 계수 | 대부분 0 |
| `depth_scale` | depth 원값 → m 환산 | 0.001 |
| 실제 해상도 | 요청이 거부되면 다른 값이 온다 | — |
| 현재 노출·게인 | 우리가 건 값이 실제로 걸렸는지 확인용 | — |

`D435I_COLOR_REF` 만 예외로 적어뒀다 — **영상 파일을 볼 때처럼 카메라가 없는 경우의 대체값**이다.
다른 해상도는 세로 비율로 환산한다(실측 0.03px 이내).

## 3. 출력 — 코드가 내놓는 것

`measure()` 가 30프레임을 모아 중앙값 하나로 낸다.

| 이름 | 단위 | 뜻 |
|---|---|---|
| `lateral` | m | 태그 정면축에서 좌우로 벗어난 거리. **+ 면 지게차가 오른쪽** |
| `forward` | m | 태그면까지 남은 거리 |
| `heading_deg` | 도 | 지게차가 태그 정면축과 틀어진 각 |
| `vertical` | m | 카메라높이 − 태그높이 |
| `distance` | m | 직선거리 |
| `z_optical` | m | 광축 방향 거리 |
| `tilt_deg` | 도 | 태그가 얼마나 돌아가 있나 (pitch·yaw 합) |
| `heading_sigma_deg` | 도 | **`heading` 을 몇 도 오차로 아는가** |
| `tag_px` | px | 태그 한 변의 화면 크기 |
| `reproj_rms_px` | px | 구한 자세로 코너를 되찍은 오차 |
| `decision_margin` | — | 검출 확신도 (저조도에서 떨어짐) |
| `hamming` | — | 고친 비트 수. 0 이 아니면 의심 |
| `spread` | — | 대표값의 표준오차 |
| `n` | — | 실제로 쓴 프레임 수 |
| `reliable_angle` | T/F | 각도를 믿어도 되나 |
| `stable` / `reasons` | T/F | 명령을 내도 되나 / 아니면 왜 |

## 4. 설계 — 우리가 고른 기준값

| 이름 | 값 | 근거 |
|---|---|---|
| `TAG_ID` / `TAG_FAMILY` | 1 / tag36h11 | 오검출이 가장 적은 계열 |
| `COLOR_SIZE` | 1920×1080 | D435i 컬러 최대. 20cm 태그 5.4m 까지 |
| `IR_SIZE` | 1280×720 | IR 은 fx 가 1/3 이라 거리도 1/3 |
| `MIN_TAG_PX` | 20 | 19.5px 에서 검출률 89.3% |
| `STABLE_TAG_PX` | 50 | 통념값, 실장비 검증 전 |
| `MAX_REPROJ_RMS_PX` | 2.0 | 코너 잡음 바닥의 약 6배 |
| `MIN_DECISION_MARGIN` | 20 | 저조도 하한으로만 |
| `RELIABLE_TILT_DEG` | 10 | 구방식. `heading_sigma_deg` 로 대체됨 |
| `MAX_HEADING_SIGMA_DEG` | 0.5 | `HEAD_TOL_DEG` 의 1/4 |
| `SIGMA_SAMPLES` | 60 | 60개면 1.4~3.4ms |
| `DEFAULT_QUAD_BLUR` | 0.0 | 전처리 9가지 비교에서 안 넣는 게 최선 |
| `MEASURE_FRAMES` | 30 | 흔들림이 1/5.5 로 |
| `MEASURE_MAX_FRAMES` | 150 | 이만큼 봐도 못 모으면 포기 |
| `STABLE_LATERAL_M` | 0.010 | 표준오차 상한 |
| `STABLE_HEADING_DEG` | 0.30 | 위와 같음 |
| `DEPTH_TOL_COEF` / `_FLOOR_M` / `_MAX_Z` | 0.05 / 0.02 / 1.5 | depth 오차가 z² 로 커짐 |
| `LAT_TOL_M` | 0.030 | 명령 하한이 17mm 라 그 밑은 무의미 |
| `HEAD_TOL_DEG` | 2.0 | 옆이동이 자동으로 0 으로 만듦 |
| `STEP_M` | 1.0 | 1m 씩이면 1.46배 느려짐 |
| `STOP_M` | 1.50 | 1.26m 보다 가까우면 태그가 화면 위로 잘림 |
| `ROT_MAX_SEC` | 15 | 폭주 방지 |
| `SIDESTEP_BACKWARD_GAIN_DEG` | 0.0 | 0 = 회전 작은 쪽 |
