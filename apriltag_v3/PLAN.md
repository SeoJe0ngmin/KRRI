# apriltag_v3 개발 계획 — "여러 번 수정하며 왕복"을 없애고 한 번에 들어가 서기

작성 2026-09-11. 근거: 2026-09-07 광운대 실차 로그(v1 11회·v2 2회) 분석 + 선행연구 조사(`prior_art_docking.md`).
v3 는 v2 를 그대로 복사해 시작했고, 이후 모든 개발은 v3 에서만 한다. v1·v2 는 참조용으로 동결.

## 0. 목표와 제약

**목표** — 지게차가 태그를 보고 **한 번 정렬 → 낮은 정속으로 쭉 들어가 → 지연·관성을 예측해 한 번에 정지**한다.
정지 후 오차 ±3 cm / ±2°(허용치는 현장 사양으로 확정 예정). 동작이 부드럽고 결단력 있게 보여야 한다(수요기업 요구).

**제약**
- 명령은 CAN 5개만: 정지 / 전진 / 후진 / 제자리회전 L / R. **곡선(조향+전진 동시) 주행은 하지 않는다.**
- 스로틀 크기(byte2)는 준비례일 가능성 — 확인 전까지 속도 프로파일은 옵션.
- 센서: RealSense D435i 컬러 1080p@30fps + 자이로 200 Hz. 태그 tag36h11 30 cm 하나.

## 2. 설계 변경 10개 + 1

각 항목: 지금 → 문제 → v3 → 효과·주의.

### ① 측정 방식 — 정지·측정 → 움직이며 연속 추정
- 지금: 완전정지 → `measure()` 30프레임 중앙값(~1 s) → 동작 1개 → `SETTLE_SEC` 0.8 s. 직진 중 카메라는 정지 트리거로만.
- 문제: 사이클마다 ~1.8 s 정지(21스텝=40 s). "새 측정=새 진실"이라 기억이 없음. 직진은 개루프.
- v3: 프레임마다 검출, 축별 **등속 칼만** `[x, v]`(예측 x+=v·Δt, 보정 K=PHᵀ/(HPHᵀ+R)). 매 프레임 `(x̂, v̂, σ)`. heading 은 자이로 200 Hz 로 예측.
  **구동기 모델은 필터에 넣지 않는다** — 무엇을 명령했든 v 는 카메라로 잰다(구동기가 비반복이라 모델이 틀릴 여지를 없앰).
- 효과: 대기 0, 속도 추정 확보(⑦의 전제), 한 프레임 튐이 행동을 못 만듦.
- 주의: 회전 중 카메라 불신 → predict-only. 카메라 지연 ≈100 ms → 타임스탬프로 `z + v̂·τ_cam` 외삽. 개발엔 프레임별 로그 필요.

### ② lateral 계산 — 태그 yaw 회전 → 방위각 + 필터된 heading
- 지금(확인 필요): 프레임별 태그 yaw 로 카메라 위치를 태그축 기준으로 회전시켜 lateral 산출.
- 문제: yaw 오차 δψ × 거리 = lateral 오차. 8 m 에서 1° = 140 mm. 우리 원거리 잡음과 일치.
- v3: 방위각 `β = atan2(t_x, t_z)`(태그 중심 픽셀 → 거리 무관 정밀) + 필터된 heading ψ̂ 로 `lateral = d·sin(ψ̂ − β)`(부호는 코드 규약).
- 효과: lateral 잡음이 "프레임 yaw × 거리"에서 "필터 heading × 거리"로. ④에서 원거리엔 lateral 자체를 안 쓰므로 5 m 이하만 정밀하면 됨.
- 첫 작업: `src/models/detection/detection_pose.py` 의 현재 식·부호 확인.

### ③ heading — 태그 yaw 그대로 → 자이로 기준 + 조건부 카메라 보정
- 지금: heading_deg 중앙값을 절대 기준으로. `reliable_angle` 은 tilt ≥ 10° 만.
- 문제: 정면에서 ±ψ 두 해가 거의 같은 그림. 3.3 m 에서 ±10° 구별 불가. 이동 중엔 틀린 해가 재투영오차가 더 낮은 경우도 있음(Liu 2021). 양봉 분포라 중앙값도 잘못 고름.
- v3: 상태 `[ψ, b]`(heading, 자이로 바이어스). 예측 `ψ += (ω−b)·Δt`. 카메라 yaw 보정은
  ① |tilt| > ~15°(정면 원뿔 밖) ② 두 해 오차비 err1/err2 ≤ 0.2 ③ 두 해 중 ψ̂ 예측에 가까운 쪽 ④ 마할라노비스 게이트 통과 — 모두 만족할 때만. 아니면 translation 만 사용.
  정지 상태(|ω| < 0.3°/s) 1~2 s 평균으로 바이어스 재추정(회전 직전마다). 프레임간 yaw 점프가 자이로로 설명 안 되면 flip 으로 판정.
- 효과: heading 연속·단봉. 회전 블라인드 구간이 자연히 이어짐. 최종 정면 구간은 정렬점에서 비스듬히 본 마지막 yaw + 자이로 적분.
- 장기: 태그 2개(오프셋/기울임)면 문제 자체가 사라짐.

### ④ 원거리(10 → ~5 m) — 전부 맞추기 → 방위각과 거리만
- 지금: 10 m 부터 lateral·heading 을 허용치에 맞추려 함(σ 60~145 mm).
- v3: d > ~5 m 에선 제어변수 = **방위각 β 하나**. 태그가 화면 중앙(또는 접근선 위 목표점 방향)에 오게 한 번 회전 → 직진. |β| 가 임계(5~10°, 방위 잡음보다 훨씬 큼)를 넘을 때만 정지·회전. lateral·heading 은 표시만.
- 효과: 원거리 왕복 제거. 문헌도 이 거리에서 마커 정밀정렬을 하지 않음(staging 1~3.5 m).

### ⑤ 횡 정렬 — 노이즈마다 사이드스텝 → 정렬점에서 1회
- 지금: v1 은 lateral > tol 이면 언제든 90° 사이드스텝. v2 는 T 조준, 가까워지면 기하가 특이해져 회전 반복 + 후진.
- v3: **정렬점 = 태그면 앞 ~5 m**. 도달 → 정지 → N프레임 → ②③으로 y, ψ̂ → **회전–직진–회전 1회**로 접근선 위에(autodock `parallel_correction`, Poreski β=90°−α). 회전량을 아끼려면 v2 의 T 조준(비스듬히 가서 축에 올라탐)도 가능 — 곡선 없이. 1회 재측정 → 잔차 < k·σ 면 진입.
- 왜 5 m: 태그 픽셀 충분, lateral 관측 가능, 뒤에 2 m 직진이 남아 낮은 정속 ≥10 s 확보.
- 효과: 사이드스텝은 문헌 표준 — 10 m 에서 노이즈에 반복한 것이 문제였을 뿐.

### ⑥ 데드밴드 — 고정 30 mm → k·σ(거리) + 히스테리시스
- 지금: `LAT_TOL_M=0.030`, `HEAD_TOL_DEG=2.0` 고정. `stable=False` 여도 행동. 매 사이클 재평가.
- 문제: Poreski 임계각 스윕 0.5°→23 %, 2°→53 %, 4°→27 % — 잡음보다 작은 임계는 정지 과다로 실패.
- v3: 행동 임계 `T_high = max(허용치, k·σ̂(d))`(k≈2~3, σ̂ 는 필터 P 또는 R(d,φ) 모델). |e| > T_high 가 N프레임 연속일 때만 보정. 한 번 |e| < 허용치에 들면 잠금 → T_high 다시 넘을 때까지 안 건드림. 최종 합격은 3 m 근처 필터값(σ 수 mm)으로 판정.

### ⑦ 직진 — "T초 가기" → 보며 가다 예측 정지
- 지금: 거리→시간(`fwd_time_model`) 개루프. v2 는 카메라 조기정지(고정 리드 0.15 m, 3프레임 확인).
- 문제: 1 s 명령 CV 108 %, 3 s 부터 ~10 %. 지연·관성·속도(run 마다 10~30 %)가 전부 거리 오차. 고정 리드는 속도가 다르면 틀림.
- v3: 명령시간 개념 삭제.
  ```
  매 프레임:  x̂, v̂
  정지 예측:  x_stop = x̂ − [ v̂·τ_d + c(v̂) ],   c(v) = v²/(2a)
  발령:       x_stop ≤ 목표 + m,  m = k·σ_D  (짧게 서는 쪽으로 편향 — 넘으면 후진해야 하므로)
  정지 명령은 t+τ_d 에 효력 → 명령 버퍼로 그동안 forward 가 이어짐을 예측에 포함
  ```
  마지막 구간은 **낮은 정속으로 ≥2~3 s**(예: 마지막 0.5~0.6 m 를 0.15~0.2 m/s). 2 s 미만은 순수 과도상태라 "빨리 가다 멈추고 크립 재시동"은 불리 — 한 번에 선다. stop 후에도 태그가 보이므로 필터 계속 → 코스팅 끝 위치 파악 → 1회 확인. 잔차 > 허용치면 **학습형 펄스 1회**(펄스폭→거리 표, 결과로 갱신).

### ⑧ 지연·관성 모델 — 상수 → τ·a 두 물리량, 정지마다 갱신
- 지금: `AIM_STOP_LEAD_M 0.15`, `ROT_LEAD_DEG 2.5`, `SETTLE_SEC 0.8` — 한 속도에서 한 번 잰 상수.
- v3: `D(v) = τ_d·v + v²/(2a)`. 정지마다 30 fps 속도 궤적에서 `τ_obs`(stop 명령 → v̂ 꺾이는 시각), `a_obs`(꺾인 뒤 기울기) 읽어 `τ ← 0.8τ + 0.2τ_obs` 식으로 갱신(또는 RLS → σ 도). 방향(전/후)·회전(τ_r, α_r) 별도, 적재/비적재 두 세트. 범위 이탈 시 경고(바닥·짐 변화).
  실측 14 cm ≈ 0.28×0.5 → 거의 지연항. 감속 램프 유무는 궤적으로 확인.
  변동성 예산 `σ_D² ≈ (τ·σ_v)² + (v·σ_τ)² + σ_c²` — **σ_τ 실측이 최우선**(0.05~0.1 s → 0.28 m/s 에서 1.4~2.8 cm).
- robust 의 출처: 모델 정확도가 아니라 **저속(D 가 작음) × 매번 갱신**. 훈련·데이터셋 없음 — float 몇 개.

### ⑨ 회전 — 고정 리드 → 가변 리드 + 소각 펄스 + 바이어스 + 워치독
- 지금: `rotate_to` 가 자이로 yaw 보며 목표−2.5° 에서 끊음. 오버슈트 대부분 ±2°, 가끔 +8°. 회전속도 CV 32 %.
- v3: 정지 조건 `θ_target − θ̂ ≤ ω̂·τ_r,stop + c_r(ω̂) + m_θ`. ω̂ 는 자이로 직접(속도 변동 무관). **τ_r,stop 은 시작지연 0.85 s 와 별개로 실측**(stop 시각 vs ω 감소 개시). 실측 코스팅 1.3° ≈ ω×0.19 s.
  <10° 소각: 정속 구간 없음 → 펄스 표(펄스폭→각), 매 회 자이로로 갱신. 회전 전 정지 1~2 s 자이로 평균 → 바이어스. 명령 후 1.5 s 넘게 ω≈0 이면 "미반영" → 재전송/경고.
- 효과: 남는 불확실성 ≈ 지연 지터 × ω ≈ 0.7°.

### ⑩ 속도 — 풀속 하나 → (확인 후) 구간별 속도
- 전제: byte2 스윕(137/147/167/187 × 3 s)으로 준비례 확인 + 속도표 + 각 속도의 D(v) + 데드존.
- v3: 구간별 **한 속도씩** — 10→5 m 는 0.28, 정렬점→정지는 0.15~0.2. 연속 램프는 안 함(드라이브 자체 램프 가능성, 짧은 재시동 회피). 비례가 아니면 풀속 유지 + 마지막 구간 ≥2~3 s 확보 + ⑦⑧ 예측.
- 회전 2단 속도(byte1 ±10)는 "안 한다" 범주인지 결정 필요.

### ⑪ 좌표 — 회전중심 환산을 `plan_aim` 안에서만 → 측정 직후 한 번
- 지금: `CAM_TO_PIVOT_M=1.46` 은 `plan_aim()` 안에서만 사용. `plan_lateral_clear`(사이드스텝)·`plan_step` 나머지 분기는 카메라 기준.
- v3: 측정(또는 ① 추정기 출력) 직후 `lat_p = lateral − A·sin h`, `fwd_p = forward + A·cos h` 로 **한 번 환산**해 모든 판단이 회전중심 좌표를 쓴다. 추정기 상태를 아예 "회전중심 위치"로 정의.
- 효과: 회전 뒤 유령 lateral 구조적으로 소멸. 작은 리팩터 — 첫 코드 작업 후보.

## 3. 새 주행 흐름

```
[10 → ~5 m]  방위각+거리만. 한 번 겨냥 회전 → 직진. 방위 임계 넘을 때만 정지·회전.
[~5 m 정렬점] 정지 → N프레임 → 회전–직진–회전 1회로 접근선 위에 → 1회 확인.
[5 → 3 m]    낮은 정속 ≥2~3 s 직진, 필터가 위치·속도 추적, heading 소폭 보정만.
[정지]       x̂ + v̂·τ + coast(v̂) ≥ 목표 되는 순간 stop. 한 번에.
[정지 후]    1회 재측정. 잔차 있으면 학습형 펄스 1회. τ·a 갱신.
```
지금(v2) 과의 대비: `정지→재고→돌고→정지→재고→가고(눈감음)→정지→재고→… ×21` → `한 번 정렬 → 쭉 → 예측 정지 → 확인`.

## 4. 개발 순서

### 지금 (사무실, 지게차 없이)
코드는 데이터 없이 전부 쓸 수 있다. 실데이터는 **숫자(계수) 맞추기와 최종 확인**에 쓴다.
1. `detection_pose.py` lateral 식 확인(②) — 읽기.
2. 회전중심 환산을 측정 직후로(⑪) — 작은 리팩터.
3. 등속 칼만 + 3σ 게이트 + 타임스탬프 외삽 클래스(①). heading 필터 `[ψ, b]`(③).
4. 정지 예측 + τ·a 온라인 갱신(⑦⑧), 회전 가변 리드·펄스 표·워치독(⑨).
5. 원거리 방위각 모드·정렬점·데드밴드/히스테리시스(④⑤⑥) 를 `plan_step` 에.
6. **시뮬레이터**로 검증 — v1 의 `sim.py / sim_engine.py / sim_measure.py` 를 v3 에 맞게. 실측 파라미터(지연 0.5/0.85 s, 관성 14 cm/1.3°, 속도 0.28, 잡음 3 m ±9 mm·7~10 m 60~145 mm, 스파이크·flip)를 넣고 "왕복 사라지나, 몇 스텝, 3 m 에서 몇 cm" 확인.

## 7. 작업 규칙 (v3)
- 개발은 v3 에서만. v1·v2 는 수정하지 않는다(참조).
- 추정기에는 구동기 모델을 넣지 않는다. 구동기 파라미터(τ, a, 속도표)는 정지 판단에서만, 온라인 갱신.
- 모든 판단은 회전중심 좌표로. 카메라 좌표는 측정 단계에서 끝낸다.
- 새 파라미터는 config 에 인라인 주석과 함께. 실주행은 `--record-events`(config 스냅샷 포함) 필수.
