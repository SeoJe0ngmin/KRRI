# docking_systemv2 / robust_docking_v5

실행 순서는 [run.md](run.md), 사람이 넣는 값은 [configs/common.json](configs/common.json)에 있습니다. 기존 `docking_system` 및 `apriltag_v4`는 이 실행본에서 변경하거나 import하지 않습니다.

## 관측과 재계획

정지 준비 → Enter → 태그 미검출 시 60°씩 탐색 → 태그·VO·gyro 관측으로 현재 위치 추정 → 최대 6단계 후보 탐색 → 첫 동작만 실행 → 정지 후 관성·되튐을 계속 관측 → 실제 위치에서 다시 탐색합니다.

일반 접근은 입구 중심선의 좌우 오차와 방향 오차를 함께 줄입니다. 예상 태그 잘림 전 마지막 구간에서는 별도의 각도 통과 조건 대신 포크 앞끝의 목표면 도착 좌우 오차를 사용합니다. 태그가 임의로 안 보인 한 프레임을 진입 시작점으로 사용하지 않습니다.

약한 회전은 전환점 전 1.5m 영역부터 사용하되, 방향 목표를 없애는 시점과 구분합니다. 방향 목표는 유지하다가 마지막 정렬 영역(전환점 전 0.15m)에서만 도착 좌우 판정으로 바꿉니다. 이 영역·영상 여백·잔여 이동 시간 등 내부 기준은 측정된 정확도 상한이 아닌 운영용 설정이며 `docking/config.py`에 모았습니다. 정지 반복성이 좋아도 실제 계통 오차가 작다고 단정하지 않습니다.

태그 보정은 같은 VO 좌표계에 옮긴 여러 관측의 합의와 기존 위치와의 일치 검사를 거칩니다. VO 재시작은 위치 기준 상실로 처리하고, gyro는 짧은 영상 사이의 회전만 보조합니다. 큰 태그/VO 충돌은 정지 후 재관측합니다. 회복 시 새 위치에서 새 계획을 계산합니다.

## I/O와 CPU

| 실행 단위 | 역할 / 밀렸을 때 처리 |
|---|---|
| 카메라 프로세스의 캡처 스레드 | SDK blocking read를 담당. 최신 영상 1개만 보관하고 대체 수 기록 |
| 별도 IMU callback | 200/100Hz 원시 샘플·시간 확인. 영상 버림과 무관하게 gyro를 보관 |
| 카메라 프로세스 | IR-depth VO/태그 계산. 결과를 먼저 전달하고 로그·JPEG는 이후 처리 |
| 계획 프로세스 | 제한된 beam search. 계산 중에는 차량 중립. 늦은/다른 위치 기준의 결과는 폐기 |
| CAN 프로세스 | v4 프레임만 반복 송신. 명령 갱신 기한·TXACK·버스 오류 감시. 만료 후 자동 재출발 없음 |
| 주 제어 루프 | 입력·최신 관측·계획 결과를 기다리지 않고 확인. 키 입력도 비차단 처리 |
| 기록/콘솔/화면 스레드 | bounded queue·짧은 메모리 교환. 디스크·SSH 출력·브라우저 대기가 제어 루프를 막지 않음 |

CPU 계산이 없어지는 것은 아닙니다. 영상 큐 길이 1, 제한된 특징점/탐색 폭, OpenCV·BLAS 스레드 제한으로 적체를 줄입니다. 오래된 영상을 모두 처리하는 대신 최신 영상을 처리하며 누락은 지표로 남깁니다. 일반 Linux/Python에서 실행하므로 하드 실시간 보장은 아닙니다. 정지 갱신이 늦어지면 독립 CAN 프로세스가 임대 만료를 감지하지만, 드라이버 자체 정지나 전원 단절에는 물리적 정지가 필요합니다.

## CAN 고정 테이블

표준 ID `0x1E3`, byte1=조향, byte2=전후진. 나머지 여섯 바이트는 항상 127입니다.

| 명령 | byte1 | byte2 |
|---|---:|---:|
| 중립 | 127 | 127 |
| 일반 전진 | 127 | 67 |
| 최종/진입 전진 | 127 | 97 |
| 후진 | 127 | 187 |
| 일반 좌/우 회전 | 157 / 97 | 127 |
| 최종 구간 약한 좌/우 회전 | 147 / 107 | 127 |

제어 ID `0x2E3`는 v4 driving-mode 배열과 counter만, heartbeat `0x764`는 `[0]`만 사용합니다. 주행 프레임의 포크 byte4는 중립 고정이며, 모드 프레임의 byte4 counter와 혼동하지 않습니다. fork/lift/reach/동시 조향·직진 명령은 허용하지 않습니다.

## 로컬 회귀 검사

```bash
cd docking_systemv2/robust_docking_v5
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m unittest discover -s tests -v
```

NumPy/OpenCV가 필요합니다. CANlib API는 메모리 모의 장치로 대체하며 테스트에서 실제 CAN을 열지 않습니다. 실제 LK/PnP 합성 영상, IMU 잡음/시간 오류, 관측 기준 재계획, 태그 충돌, 모의 차량 관성, CAN 전체 바이트와 송신 오류/기한 만료, 비차단 큐를 검사합니다. 하드웨어 실행에는 기존 Jetson 가상환경의 `pyrealsense2`, `pupil_apriltags`, Kvaser CANlib가 추가로 필요합니다.
