# OS·CPU 차이는 아래 마커(; sys_platform / platform_machine)가 알아서 가른다 — 파일 하나로 다 된다:
#   x86(그램 Windows·WSL) pyrealsense2 는 PyPI 휠,  arm64(VM·Jetson) 는 마커로 빼고 소스 빌드,
#   macOS 는 pyrealsense2-macosx,  canlib·keyboard 는 macOS 만 뺀다.

# 리눅스 arm64(Jetson, 맥북의 Ubuntu VM)는 PyPI 에 휠이 없어 소스 빌드로 넣는다
# (librealsense v2.58.3, -DFORCE_RSUSB_BACKEND=ON -DBUILD_PYTHON_BINDINGS=ON).
# 그래서 그 조합은 여기서 뺀다 — 안 빼면 pip install -r 이 이 줄에서 통째로 실패한다.

# ── 실주행 전용 (CAN 으로 지게차를 움직일 때. Windows/Linux 만) ──────
# canlib 는 pip 만으로 끝나지 않는다. **Kvaser 드라이버를 OS 에 먼저 깔아야**
# import 시점에 네이티브 DLL 을 찾는다:
#     Windows       kvaser.com -> "Kvaser Drivers for Windows" 설치파일
#     Linux/Jetson  kvaser.com -> linuxcan 소스 받아 make && sudo make install
# macOS 는 제외한다 — Kvaser 가 CANlib API 를 macOS 에 안 낸다(MacCAN 은
# CAN API V3 라는 다른 규격이라 control_forklift_v2 가 그대로는 못 쓴다).
# 따라서 macOS 에서는 실주행이 안 되고, dry-run/시뮬/분석만 된다.
# keyboard 는 리눅스에서 root 가 필요하지만 control_forklift_v2 가 최상단에서
# import 하므로 젯슨 실주행을 위해 남긴다. macOS 만 뺀다(엔터로 폴백된다).
canlib==1.33.358                   ; sys_platform != "darwin"
keyboard==0.13.5                   ; sys_platform != "darwin"
