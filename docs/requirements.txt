# canlib 는 pip 만으로 끝나지 않는다. **Kvaser 드라이버를 OS 에 먼저 깔아야**
# import 시점에 네이티브 DLL 을 찾는다:
#     Windows       kvaser.com -> "Kvaser Drivers for Windows" 설치파일
#     Linux/Jetson  kvaser.com -> linuxcan 소스 받아 make && sudo make install
# macOS 는 제외한다 — Kvaser 가 CANlib API 를 macOS 에 안 낸다(MacCAN 은
# CAN API V3 라는 다른 규격이라 control_forklift_v2 가 그대로는 못 쓴다).
# 따라서 macOS 에서는 실주행이 안 되고, dry-run/시뮬/분석만 된다.
# keyboard 는 리눅스에서 root 가 필요하지만 control_forklift_v2 가 최상단에서
# import 하므로 젯슨 실주행을 위해 남긴다. macOS 만 뺀다(엔터로 폴백된다).
